# kidan-project

令和の学校を舞台にした、分岐型ホラーサウンドノベルの企画・開発リポジトリです。

## Concept

この作品で重視するのは、単なる「学校の怪談集」ではなく、次の体験です。

- 癖の強い語り手そのものが面白い
- 会話中の選択によって、話が思いがけない方向へ分岐する
- 幽霊・人間・勘違いの境界が曖昧な、不気味さが残る
- 周回や選択順によって、同じ人物の別の顔が見える
- やり込んだ先に、通常の怪談とは別格の深いルートが潜んでいる

メタ的な演出は作品の主題にはせず、違和感や不気味さを強めるスパイスとして扱います。

## Direction

現時点では仕様を固定しすぎず、まずはキャラクターと一本一本の怪談、そして分岐そのものの面白さを検証します。

技術候補としては、ノベルゲーム制作に特化した Ren'Py を第一候補としています。
