# コンセプト

## 仮ジャンル

分岐型ホラーサウンドノベル。あ

舞台は令和の学校を想定する。ただし「令和らしさ」を前面に押し出すのではなく、スマートフォンやSNSなどは現代の日常として自然に存在させる。

## 作品の核

この企画で最も重視するのは、怪談そのものだけではなく「誰がその話をしているのか」という面白さ。

プレイヤーが感じてほしい中心的な感情は、次のようなもの。

- この人、次は何を話すんだろう
- 話より語っている本人のほうが怖くないか
- この選択肢でそこまで話が変わるのか
- 前に会ったときと印象がまるで違う
- 何本も見たあとで、別の大きな何かが潜んでいたことに気づく

## 重視する要素

### 語り手の癖

属性だけでなく、話し方、倫理観、反応、隠し事、主人公との距離感によって人物を立たせる。

「怪談を聞きたい」だけでなく「この人物にもう一度会いたい」が周回の動機になることを目指す。

### 分岐

選択肢は単なる好感度変化ではなく、怪談そのものの展開、ジャンル、真相、語り手の人物像まで変化させる。

同じ人物でも、選択順や既読シナリオによって別の話や別の反応が見える構造を検討する。

### 不気味さ

派手な怪物よりも、説明しきれない違和感を重視する。

幽霊なのか、人間の悪意なのか、勘違いなのか、語り手が嘘をついているのかを断定しない話も積極的に採用する。

### 深い隠しルート

すべての怪談を一本の真相へ回収することはしない。

独立した怪談が多数存在する中で、特定の順番や選択、周回によってだけ入れる、通常とは別格の深いルートを用意する方向で検討する。

## メタ要素

メタ演出は主題にしない。

周回時に台詞がわずかに変わる、まだ選んでいない選択肢を知っているような反応をする、ロード前の出来事を覚えているように見える、といった演出を少量だけ混ぜる。

重要なのは「ゲームの世界の仕組みを説明する」ことではなく、プレイヤーに一瞬だけ「今の何？」と思わせること。

## 避けたい方向

- SNSや生成AIなどを並べただけの「令和あるある怪談集」
- すべての怪談が実は一つの組織や超常現象の仕業だった、という過剰な一本化
- メタ要素が前面に出て、通常の怪談が単なる伏線になる構成
- システム開発に力を使いすぎて、シナリオ制作が進まなくなること

## 当面の目標

一本の短い怪談と一人の強いキャラクターを作り、複数方向へ分岐させる小規模なプロトタイプを完成させる。
