# キャラクター方針

## 基本方針

この作品では、怪談の内容と同じくらい「語っている人物そのもの」を魅力にする。

最初から人数を固定せず、まず一人ずつ作り込み、実際に話を読んで「もう一度会いたい人物になっているか」を確認する。

## キャラクター設計で見るポイント

- 第一印象と、話を聞いた後の印象に差があるか
- 話し方だけで誰か分かるほど癖があるか
- 善人／悪人だけでは説明できない倫理観を持っているか
- その人物だから成立する怪談になっているか
- 別ルートで意外な側面を見せられるか
- 主人公との距離感そのものに緊張感や面白さがあるか

## 仮キャラクター案

以下は方向性確認用の仮案。採用確定ではない。

### 荒木 透

穏やかで話がうまく、一見すると最もまともに見える人物。

ただし、主人公が質問する前に答えたり、以前の選択を知っているような反応をすることがある。

メタ演出を使う場合も、本人が露骨にゲーム世界を認識しているとは説明しない。

### 久我 美月

頭の回転が速く、かなり感じが悪い。幽霊や呪いを否定する現実主義者。

彼女の話は人間の悪意や集団心理を中心にする。冷淡に見える一方で、別の話では危険を冒して他人を助けるなど、単純な性格にしない。

### 百瀬 圭

明るく話が面白い人物。怪談中にも笑える脱線を挟み、息抜きになる。

しかし、彼の話には不自然なほど頻繁に死者が出る。本人だけがいつも生き残る。

### 水科 奈々

非常に怖がりで、自分の怪談を話しながら自分で怯える。

一見すると頼りないが、彼女の証言だけは不思議なほど事実と一致する、という特徴を持たせる案。

## 次に作るもの

まず一人を選び、以下を具体化する。

1. 外見
2. 話し方
3. 主人公との関係
4. 最初に語る怪談
5. その怪談の主要分岐
6. 別ルートで見せる意外な面

人数を増やすのは、この一人が面白いと確認してからにする。
