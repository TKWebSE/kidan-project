# シナリオ構造

## 基本構造

一本の巨大なストーリーを一本道で追うのではなく、複数の人物と複数の怪談が枝分かれして存在する構造を想定する。

プレイヤーは人物や会話中の選択肢を選び、同じ人物でも異なる展開を発見していく。

## 分岐の考え方

分岐には複数の層を持たせる。

### 会話内分岐

その場の選択肢によって怪談の展開が変わる。

単なる台詞差分ではなく、可能であれば「幽霊の話だったものが人間の話になる」「被害者だと思っていた人物が加害者に見える」など、話の意味まで変える。

### 選択順による分岐

誰と先に話したかによって、主人公が持っている情報が変わる。

その結果、同じ人物に対して新しい質問をしたり、相手の嘘や矛盾に気づけるようにする。

### 既読・周回による分岐

過去に見た話やエンディングによって、ごく一部の台詞や選択肢が変化する。

これはメタ演出にも利用できるが、通常の分岐を邪魔しない程度に抑える。

## メタ演出の扱い

メタ要素はスパイス。

目安として、多くのシナリオはメタ要素なしで単独の怪談として成立させる。

例：

- 二周目だけ一文が違う
- 選択肢が表示される前に相手が回答する
- ロード前の出来事を覚えているような台詞が一度だけ出る
- 特定条件で、通常は存在しない選択肢が混ざる

これらを必ず説明・回収する必要はない。

## 深いルート

通常プレイとは別に、やり込みによって発見できる大規模な隠しルートを検討する。

ただし、全怪談がそのルートの伏線になる構造にはしない。

「普通に怖い怪談をたくさん楽しめる」ことが前提であり、その森の奥に別格の何かが潜んでいる、という位置づけにする。

## プロトタイプ案

最初の試作では、以下だけ実装する。

- 語り手：1人
- 基本となる怪談：1本
- 主要分岐：3〜4方向
- 短いエンディング：複数
- 周回時だけ発生する小さな違和感：1つ程度

この試作で、文章、キャラクター、分岐を繰り返し遊ぶこと自体が面白いかを確認する。
